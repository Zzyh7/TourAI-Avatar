## 3. API Key 配置

将项目根目录下的 `.env.example` 复制为 `.env`，填入真实的 API Key：

```bash
cp .env.example .env
```

编辑 `.env`，至少填写以下三项：

```env
# 必填：DeepSeek 大模型
DEEPSEEK_API_KEY=sk-your-deepseek-api-key-here

# 必填：阿里百炼（多模态拍照识景 + 语音识别）
DASHSCOPE_API_KEY=sk-your-dashscope-api-key-here

# 必填：高德地图 MCP
AMAP_API_KEY=your-amap-api-key-here

# 可选：豆包语音合成（不填则使用 Edge-TTS 免费版）
DOUBAO_TTS_API_KEY=your-doubao-tts-api-key-here
```

| Key | 用途 | 申请链接 |
|-----|------|---------|
| `DEEPSEEK_API_KEY` | 大模型对话 | https://platform.deepseek.com/ |
| `DASHSCOPE_API_KEY` | 拍照识景 + 语音识别 | https://dashscope.console.aliyun.com/ |
| `AMAP_API_KEY` | 高德地图 MCP | https://lbs.amap.com/ |
| `DOUBAO_TTS_API_KEY` | 豆包语音合成（可选） | https://console.volcengine.com/speech |

## 4. 一键部署

### Windows

```bat
双击 setup.bat
```

### macOS / Linux

```bash
bash setup.sh
```

脚本自动完成：

1. ✅ 检查 Python & Node.js 环境
2. ✅ 创建 Python 虚拟环境
3. ✅ 安装所有 Python 依赖（`requirements.txt`）
4. ✅ 安装前端依赖（`frontend/visitor` + `frontend/admin`）
5. ✅ 创建 `.env` 配置文件模板（如不存在）

### 手动部署（如脚本失败）

```bash
# 1. Python 虚拟环境
python -m venv venv
source venv/bin/activate      # macOS/Linux
venv\Scripts\activate         # Windows

# 2. Python 依赖
pip install -r requirements.txt

# 3. 前端依赖
cd frontend/visitor && npm install && cd ../..
cd frontend/admin  && npm install && cd ../..
```

## 6. Live2D 数字人部署

数字人（端口 3000）是独立服务，TourAI 后端启动后单独部署。

### 6.1 安装依赖

```bash
cd live2d/web
pnpm install
cd ../..

# Python 依赖（复用项目 venv 或全局安装）
pip install -r live2d/requirements.txt
```

### 6.2 配置环境变量

创建 `live2d/web/.env.local`：

```
NEXT_PUBLIC_SERVER_PROTOCOL=http
NEXT_PUBLIC_SERVER_IP=localhost
NEXT_PUBLIC_SERVER_PORT=8880
NEXT_PUBLIC_SERVER_VERSION=v0
```

创建 `live2d/.env`：

```
DASHSCOPE_API_KEY=你的阿里百炼Key
```

### 6.3 启动数字人

```bash
# 终端 4：Live2D API（端口 8880）
cd live2d
python main.py

# 终端 5：Live2D Web（端口 3000）
cd live2d/web
pnpm dev --port 3000
```

### 6.4 验证

| 服务 | 验证地址 | 预期 |
|------|---------|------|
| Live2D API | http://localhost:8880/docs | API 文档 |
| 数字人页面 | http://localhost:3000/sentio | 小僧数字人 + 对话界面 |

## 8. 常见故障排查

### 8.1 端口被占用

```bash
# Windows：查看端口占用
netstat -ano | findstr :8000

# macOS/Linux：
lsof -i :8000

# 使用 start.py 启动会自动释放 8000/5173/5174 端口
python start.py
```

### 8.2 数字人页面空白

- 确认 Live2D API（:8880）已启动：`curl http://localhost:8880/docs`
- 确认 `live2d/web/.env.local` 内容正确
- 清除浏览器 localStorage 后刷新

### 8.3 语音识别失败

- 确认 `DASHSCOPE_API_KEY` 已正确填入 `.env` 和 `live2d/.env`
- 确认 Live2D API 启动时输出了 `[EnginePool] ASR Engine default is DashScope`

### 8.4 语音回答没声音

- 打开管理后台 → 系统配置 → 确认音色为有效值
- Edge-TTS 推荐男声：`zh-CN-YunxiNeural`
- 检查控制台是否有 403/500 错误

### 8.5 npm install 失败

```bash
# 设置国内镜像
npm config set registry https://registry.npmmirror.com

# 或使用 pnpm（数字人前端）
pnpm config set registry https://registry.npmmirror.com
```

### 8.6 pip install 失败

```bash
# 使用清华镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 8.7 首次请求很慢

首次对话时后端需要加载 BGE 嵌入模型（~24MB），延迟约 3-5 秒。后续请求正常。
